# Vibe Research Workflow (Econ Edition v5.0)

一个面向经济学研究的循环式AI协同工作流，基于 **4板块循环** 架构，融合 [Academic Research Skills (ARS)](https://github.com/Imbad0202/academic-research-skills) 的多角色审稿与严谨性机制，帮助研究者在"理性（Why）"与"严谨（How）"之间持续迭代。

---

## 这是什么？

Vibe Research 不是AI写作助手，而是**研究协同系统**。

- 你掌握：研究问题、叙述逻辑、取舍判断
- AI协同：结构化思考、多角色审稿、证据路径提示、学术写作
- 不是：AI自动生成论文、你只负责审核

---

## 核心架构：4板块循环

```
/框架 → /实证 → /写作 → /审查 → 下一Cycle
  ↑                                  |
  └──────── 未通过（最多3轮）─────────┘
```

| 板块 | 指令 | 功能 |
|------|------|------|
| **概念框架** | `/框架` | 定义研究问题、文献研究（3级模式）、理论逻辑、因果识别（DAGs） |
| **实证检验** | `/实证` | 模型设计、基准回归、异质性/机制、稳健性检验、流程摘要自动生成 |
| **写作输出** | `/写作` | 7种写作模式（全流程/规划/提纲/修改/摘要/文献综述等）、风格校准、论断溯源审计 |
| **论证审查** | `/审查` | 5人审稿团队、7维度0-100评分、DA让步阈值、苏格拉底辅导、图表核实 |

## v5.0 核心特性（ARS增强版）

### 多角色审稿 + 评分体系
- **5人审稿团队**：主编 + 方法论审稿人 + 领域审稿人 + 视角审稿人 + 魔鬼代言人 + 编辑综合人
- **7维度评分**：方法论严谨性、文献覆盖、论证强度、写作质量、创新性、可复现性、影响力
- **决策映射**：≥80接受 / 65-79小修 / 50-64大修 / <50拒稿

### 反谄媚机制
- **DA让步阈值协议**：1-5分评分，仅≥4分才允许让步，让步率不超过40%
- **框架锁定检测**：防止AI在用户框架内"打转"，强制质疑研究问题前提

### 文献研究子工作流
- **3级模式**：探索级（快速扫描）/ 综述级（PRISMA系统综述）/ 核查级（事实核查）
- **6阶段流水线**：范围界定 → 调研执行 → 分析综合 → 综述撰写 → 评审校验 → 修订输出
- **3层来源验证**：元数据验证 → 质量分级 → 内容抽查

### 完整性关卡（不可跳过）
- **关卡2.5**：文献研究完成后
- **关卡4.5**：框架→实证之间
- **实证完整性关卡**：实证→写作之间
- **审查通过关卡**：所有7维度≥75

### 写作模式多样化
- 7种模式：full / plan（苏格拉底引导）/ outline-only / revision / revision-coach / abstract-only / lit-review
- Fidelity-Originality光谱：忠实/平衡/原创性
- 风格校准、论断溯源审计、AI高频词检测

### 苏格拉底式引导
- SCR协议（陈述-挑战-反思）
- 承诺门（防止后见之明偏误）
- 确定性触发的反驳
- 意图检测（探索性 vs 目标导向）

## 快速开始

1. 将本仓库克隆到 Claude Code 的 skills 目录
2. 创建项目目录与 `项目信息.md`
3. 输入 `/框架`，定义研究问题
4. 按照 **框架 → 实证 → 写作 → 审查 → 重复** 循环推进

---

## 核心原则

1. **以人为主体**：研究决策由你完成，AI是副驾
2. **证据优先**：AI只提供检索线索，不虚构文献
3. **结果诚实**：不管结果是否支持假设，都必须诚实报告
4. **错误不掩盖**：代码报错必须暴露并解决
5. **可迭代**：每轮循环都沉淀为可复用结构
