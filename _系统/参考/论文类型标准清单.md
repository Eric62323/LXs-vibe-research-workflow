# 论文类型标准清单 (Paper-Type Taxonomy)

**用途**：在 `/实证` Phase 1 中标注论文类型后，生成对应的审稿人期望清单。后续所有环节（回归→异质性→稳健性→完整性关卡→/审查）参照此清单执行。

---

## 1. Reduced-Form（简约式因果推断）

**定义**：利用外生变异（IV/DiD/RDD/事件研究）识别因果效应，不构建结构模型。核心是可信的识别策略，而非理论推导。

### 必须有（缺少会被直接拒）

- [ ] **清晰的识别策略**：说明外生变异来源（为什么这是外生的）
- [ ] **识别假设的显式陈述**：IV 的排他性 / DiD 的平行趋势 / RDD 的连续性
- [ ] **第一阶段结果**（IV 论文）：F-stat > 10，报告系数和方向
- [ ] **基准回归**：核心因变量的主估计结果，系数、标准误、显著性完整
- [ ] **标准误聚类说明**：聚类层级有理论依据（个体/城市/省份）
- [ ] **稳健性检验**（≥ 3 种）：替代变量、替代样本、替代模型设定

### 强烈建议（没有会被要求 R&R 补充）

- [ ] **异质性分析**：效应在不同子群体中的差异，有理论依据
- [ ] **机制/渠道分析**：因果效应通过什么路径传导
- [ ] **经济显著性**：不只报告统计显著，还说明效应的实际经济含义
- [ ] **事件研究/动态效应**（DiD/Bartik 场景）：冲击前后的时间路径
- [ ] **安慰剂检验**：用伪处理/伪 IV 验证结果不是偶然

### 加分项（区分"能发"和"发好刊"）

- [ ] **识别策略的前沿检验**：如 Bartik 的 Goldsmith-Pinkham 份额外生性检验、Rotemberg 权重分解
- [ ] **Leave-one-out 稳健性**：排除单一地区/行业后结果是否稳定
- [ ] **预趋势检验**：冲击前的平行趋势图和统计检验
- [ ] **替代解释排除**：系统排除竞争性假说
- [ ] **效应量的边际分析**：不同处理强度下的剂量-反应关系

### 与其他类型的核心区别

| 对比维度 | Reduced-Form | Structural |
|---------|-------------|-----------|
| 目标 | 估计因果效应 | 反事实模拟与政策评估 |
| 模型 | 简约回归方程 | 经济学理论推导的结构方程 |
| 外部效度 | 通常有限 | 理论上可推广 |
| 关键假设 | 识别策略的可信度 | 模型设定的正确性 |
| 审稿焦点 | "识别是否可信" | "模型是否合理" |

## 2. Structural（结构模型估计）

**定义**：基于经济学理论推导的结构方程系统，通过估计深层参数进行反事实模拟和政策评估。核心是模型的经济学合理性和估计的可信度。

### 必须有

- [ ] **明确的经济模型**：理论推导过程完整，均衡条件清晰
- [ ] **模型识别**：哪些参数可被数据识别，哪些需要校准
- [ ] **估计方法说明**：MLE/GMM/间接推断/SMM，选择理由
- [ ] **拟合优度**：模型对数据中关键矩/模式的匹配程度
- [ ] **参数估计结果**：深层参数的点估计、标准误、经济含义

### 强烈建议

- [ ] **反事实模拟**：至少一组政策相关的反事实实验
- [ ] **稳健性检验**：改变函数形式、关键校准参数、估计方法
- [ ] **与 reduced-form 结果对照**：结构模型的简化形式预测是否与已知的 reduced-form 证据一致
- [ ] **敏感性分析**：关键假设或参数变化时，结论是否稳定

### 加分项

- [ ] **模型检验/过度识别检验**：模型对未被用于估计的矩的匹配能力
- [ ] **外部效度验证**：在一个环境估计的参数能否预测另一个环境的outcome
- [ ] **计算细节透明**：优化算法、收敛标准、多重起始值
- [ ] **与已有结构模型的比较**：你的模型相对已有文献的改进

### 与其他类型的核心区别

| 对比维度 | Structural | Reduced-Form |
|---------|-----------|-------------|
| 目标 | 反事实模拟与政策评估 | 因果效应估计 |
| 理论要求 | 必须有完整的理论模型 | 不强制（但有助于解释） |
| 政策相关性 | 强（可直接模拟政策效果） | 间接（需要额外假设） |
| 审稿焦点 | "模型是否合理" | "识别是否可信" |

## 3. Theory + Empirics（理论+实证）

**定义**：先建立理论模型推导可检验的预测（命题/假说），再用实证数据检验这些预测。核心是理论与实证的紧密对应。

### 必须有

- [ ] **理论模型**：推导出明确的、可检验的命题（不只是"影响方向"）
- [ ] **命题到实证的映射**：理论命题 → 具体的实证预测 → 回归方程
- [ ] **基准实证检验**：直接检验理论预测的回归结果
- [ ] **理论与实证的一致性讨论**：结果是否支持理论预测

### 强烈建议

- [ ] **多个命题的检验**：不只检验一个预测，而是检验理论模型的多重含义
- [ ] **替代理论排除**：实证结果能否排除竞争性理论解释
- [ ] **机制检验**：实证中验证理论模型假设的传导渠道
- [ ] **定量匹配**：理论预测的效应量与实证估计的对比

### 加分项

- [ ] **结构估计**：直接估计理论模型参数（介于 reduced-form 和 structural 之间）
- [ ] **边界条件检验**：理论预测在什么条件下成立/失效
- [ ] **理论模型的简约性论证**：为什么这个模型而不是更复杂的模型

### 与其他类型的核心区别

| 对比维度 | Theory+Empirics | Reduced-Form | Formal Theory |
|---------|----------------|-------------|--------------|
| 理论 | 有，且用于推导预测 | 不强制（可选） | 有，为主要贡献 |
| 实证 | 有，且直接检验理论 | 有，为主要贡献 | 无 |
| 核心 | 理论与实证的对应 | 识别可信度 | 理论创新性 |

## 4. Descriptive（描述性分析）

**定义**：揭示新的事实、模式或现象，不做因果推断。核心贡献是"发现了什么"而非"为什么"。在经济学中通常以"新数据集 + 新事实"为卖点。

### 必须有

- [ ] **明确的研究问题**：描述的是什么现象，为什么重要
- [ ] **数据代表性说明**：样本是否具有代表性，结论可推广到什么范围
- [ ] **统计方法的合理性**：描述方法（均值/分位数/回归/分解）是否适合研究问题
- [ ] **数据质量透明**：缺失值、异常值、样本筛选的处理方式

### 强烈建议

- [ ] **跨时间/跨群体/跨地区的系统对比**：不只是"均值是多少"
- [ ] **分解分析**：Oaxaca-Blinder / Shapley / 方差分解，揭示贡献因素
- [ ] **与已有文献的对比**：你的新事实与已有认知有何不同
- [ ] **政策含义讨论**：即使不做因果推断，也可以讨论政策相关性

### 加分项

- [ ] **新的数据集/测量方法**：独特的贡献
- [ ] **可视化**：清晰展示模式的高质量图表
- [ ] **为后续因果研究铺垫**：指出哪些模式值得深入研究
- [ ] **稳健的测量**：多种测量方式得到一致结论

### 与其他类型的核心区别

| 对比维度 | Descriptive | Reduced-Form |
|---------|------------|-------------|
| 目标 | 发现事实/模式 | 识别因果效应 |
| 因果推断 | 不做 | 核心贡献 |
| 审稿焦点 | "事实是否新颖可靠" | "识别是否可信" |

---

## 5. Formal Theory（纯理论）

**定义**：通过数学模型推导新的经济学洞见，不涉及实证检验。核心贡献是"逻辑是否严密、洞见是否深刻"。

### 必须有

- [ ] **清晰的问题动机**：解释什么现象，为什么现有理论不够
- [ ] **假设的合理性**：每条假设的经济直觉和必要性
- [ ] **命题/定理的严格证明**：逻辑链条完整
- [ ] **经济直觉**：不只是数学推导，要给出经济学的直觉解释

### 强烈建议

- [ ] **与现有理论的关系**：你的模型在什么条件下退化为已有模型
- [ ] **假设的放松/稳健性**：关键假设放松后结论是否仍然成立
- [ ] **数值示例**：用具体的参数值展示模型的定量含义
- [ ] **可检验的预测**：理论能产生哪些可供未来实证检验的预测

### 加分项

- [ ] **多模型对比**：在不同模型框架下得到相同结论
- [ ] **应用的丰富性**：模型能解释多个现象
- [ ] **简洁性**：用最少的假设得到最强的结论

### 与其他类型的核心区别

| 对比维度 | Formal Theory | Theory+Empirics |
|---------|-------------|----------------|
| 实证 | 无 | 有，为核心贡献之一 |
| 审稿焦点 | "逻辑严谨、洞见深刻" | "理论与实证的对应" |

---

## 6. Survey Experiment（调查/田野实验）

**定义**：通过随机化实验（调查嵌入实验、实验室实验、田野实验）识别因果效应。核心是实验设计的内部效度。

### 必须有

- [ ] **随机化机制说明**：如何随机分配处理，是分层随机还是完全随机
- [ ] **平衡性检验**：处理组和对照组的基线特征是否平衡
- [ ] **平均处理效应 (ATE)**：主回归结果，ITT 或 CACE
- [ ] **实验设计的预注册**（如适用）：预先登记假设和分析计划

### 强烈建议

- [ ] **依从率分析**（田野实验）：实际接受处理的比例
- [ ] **异质性处理效应**：效应在不同子群体中的差异
- [ ] **外部效度讨论**：实验样本能否推广到目标人群
- [ ] ** Hawthorne/需求效应讨论**：被试是否意识到实验，是否影响行为

### 加分项

- [ ] **多处理臂设计**：不止一个处理，可以分离机制
- [ ] **长期追踪**：实验效应是否持续
- [ ] **成本效益分析**：干预的成本相对于效果的性价比

### 与其他类型的核心区别

| 对比维度 | Survey Experiment | Reduced-Form |
|---------|------------------|-------------|
| 识别策略 | 随机化 | 观测数据中的外生变异 |
| 内部效度 | 高（随机化保证） | 需要论证 |
| 外部效度 | 通常有限 | 因项目而异 |
| 审稿焦点 | "实验设计是否干净" | "识别是否可信" |

---

## 使用方式

1. **Phase 1（理解确认）**：标注论文类型，输出对应的检查清单
2. **保存到实证计划.md**：清单随项目持久化
3. **Phase 2-4**：各环节参照清单中的标准执行
4. **完整性关卡**：逐项对照清单打分
5. **/审查**：审稿人模拟参照清单中的标准
