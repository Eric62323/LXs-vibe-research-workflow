# 概念框架指南

**目的**：规范概念框架（Conceptual Framework）的构建、演化与引用方式，确保研究在**理性**与**严谨**两个维度上都经得起审稿人检验。

---

## 📐 什么是概念框架？

**定义**：一套动态论证系统，确保研究在整个过程中持续满足**理性**与**严谨**两大标准。

**理性（Why）**：论证研究主题的重要性。
- 想研究什么？（研究问题）
- 它为什么重要？（理论与现实意义）
- 为谁研究？（学术与政策受众）

**严谨（How）**：论证研究方法的恰当性。
- 你的研究问题如何与主题保持一致？（**相关性论证**）
- 你的研究设计如何匹配研究目的？（**设计匹配论证**）
- 你的数据能否支撑问题探索？（**资料充分性论证**）
- 你的方法能否有效处理问题？（**方法有效性论证**）

**类比**：
- 如果数据是砖块，实证方法是水泥，概念框架就是**建筑审批文件**——它向审稿人证明：你不仅会盖房子，还知道为什么要盖、盖给谁住、怎么保证不塌。

---

## 🧩 概念框架的双维结构

### 第一维：理性论证（Why this matters）
**任务**：说服审稿人"这个研究值得做"。

**三个核心问题**：
1. **研究问题是什么？**
   - 用一句话清晰陈述（避免模糊表述）
   - 示例：✓ "数字金融如何影响农户创业？"
   - 反例：✗ "探讨数字金融相关问题"

2. **为什么重要？**
   - **理论意义**：填补什么文献空白？（"现有研究关注城市，忽略农村"）
   - **现实意义**：解决什么实际问题？（"乡村振兴需要精准识别受益群体"）

3. **为谁研究？**
   - **学术受众**：哪些领域学者会引用？（发展经济学、金融科技）
   - **政策受众**：哪些机构会使用结论？（央行、农业部）

---

### 第二维：严谨论证（How to do it right）
**任务**：证明"我的研究设计是恰当的"。

**四大论证标准**：

#### 论证1：相关性论证（研究问题是相关性论证的结果）
**审稿人会问**："你的问题是怎么来的？"

**自查标准**：
- ✓ 问题来源于文献综述的自然推导（"文献A做了X，文献B做了Y，但缺Z"）
- ✗ 拍脑袋想出的问题（"我觉得这个现象挺有意思"）

**示例**：
```
现有文献关注数字金融对城市居民的影响（李四，2020），
但农村场景下的技术接受障碍尚未得到充分研究。
因此，本文聚焦于...
```

#### 论证2：设计匹配论证（研究设计与研究目的、问题、背景相对应）
**审稿人会问**："你的方法能回答你的问题吗？"

**匹配规则**：
| 研究目的 | 对应设计 | 常见错误 |
|---------|---------|---------|
| 因果识别 | DID/RDD/IV | 用OLS就说"影响" |
| 机制探索 | 中介效应检验 | 只跑主效应不看机制 |
| 政策评估 | 准自然实验 | 用截面数据评估政策 |

**示例**：
- 目的：识别数字金融对创业的**因果效应**
- 设计：利用支付宝县域渗透时间差异构建DID
- 匹配性：✓（准自然实验+面板数据，可识别因果）

#### 论证3：资料充分性论证（要收集的资料提供探索问题所需的原材料）
**审稿人会问**："你的数据能支撑你的论证吗？"

**充分性检查清单**：
```markdown
| 变量类型 | 理论需要 | 数据是否包含 | 测量方式 |
|---------|---------|-------------|---------|
| 结果变量Y | 创业率 | ✓ | 是否创业（0/1） |
| 核心解释变量X | 数字金融可得性 | ✓ | 支付宝县级渗透率 |
| 中介变量M | 信贷约束 | ✓ | 贷款申请批准率 |
| 控制变量 | 个体特征 | ✓ | 年龄、教育、收入 |
```

**常见问题**：
- ✗ 想研究"创业质量"，但数据只有"是否创业"（测量不匹配）
- ✗ 想做机制检验，但没有中介变量数据（资料不充分）

#### 论证4：方法有效性论证（分析方法能够有效处理问题）
**审稿人会问**："你的方法真的识别了因果吗？"

**有效性判断**：
```
数据类型 + 识别策略 → 能回答什么问题

截面数据 + OLS → 只能证明相关性
面板数据 + 固定效应 → 可控制不随时间变化的遗漏变量
面板数据 + DID → 可识别因果效应（前提：平行趋势）
```

**关键提示**：方法有效性论证中的"有效处理（如果不总是回答）"意味着——
- ✓ 即使不能完美回答因果问题，也要诚实说明方法局限
- 示例："由于缺乏工具变量，本文的基准回归仍可能存在内生性问题，因此我们进行了...稳健性检验"

## 🔄 概念框架的持续反思机制

**核心原则**：概念框架不是一次性构建的，而是需要在研究的每个关键节点**持续返回思考**。

### 反思时机表

| 研究阶段 | 反思重点 | 触发问题 |
|---------|---------|---------|
| **文献综述后** | 理性论证是否站得住 | "问题推导逻辑清晰吗？" |
| **设计方案时** | 四大严谨论证是否完备 | "我的设计能回答问题吗？" |
| **数据收集后** | 资料充分性是否达标 | "数据有缺失吗？" |
| **实证结果后** | 方法有效性是否验证 | "结果与预期不符，哪个论证错了？" |
| **写作草稿时** | 全维度自查 | "论文逻辑自洽吗？" |
| **审稿意见后** | 针对性修正 | "审稿人质疑哪个论证？" |

### 持续反思检查清单

**每完成一个阶段，重新运行这份清单**：

```markdown
## 概念框架健康度自查

### 理性维度
- [ ] 研究问题表述是否还清晰？（有没有在写作中跑题？）
- [ ] 重要性论证是否还站得住？（实证结果支持原来的意义论证吗？）
- [ ] 受众定位是否准确？（投稿期刊对口吗？）

### 严谨维度
- [ ] **相关性**：问题推导逻辑还成立吗？（文献综述需要更新吗？）
- [ ] **匹配性**：设计真的能回答问题吗？（是否需要补充稳健性检验？）
- [ ] **充分性**：数据够用吗？（是否需要补充数据或更换测量方式？）
- [ ] **有效性**：方法真的识别了因果吗？（平行趋势假设成立吗？）
```

## 📝 如何在论文中使用框架？

### Introduction 中的嵌入位置
**段落2-3**：从现有文献过渡到本文框架。

**模板**：
```
现有文献主要基于XX理论解释YY现象，但存在两个局限：
（1）忽略了ZZ因素的调节作用；
（2）未能区分AA与BB的差异。

本文基于【理论A + 理论B】，构建了一个融合性分析框架，
认为XX通过【中介M】影响YY，且这一过程受【调节变量Z】影响。
```

### Mechanism 章节的对应
**每个中介检验都要呼应框架**：
```
根据本文的概念框架，数字金融对创业的促进作用可能通过
"信贷约束缓解"这一中介实现。表5的结果显示...
```

### 结论中的反思
**不仅总结结果，还要评估框架**：
```
本研究证实了XX理论在YY情境下的适用性，
但也发现【意外结果】，提示未来研究需引入ZZ视角。
```

## 🚫 常见错误与修正

| 错误类型 | 具体表现 | 违反了哪个论证 | 修正方法 |
|---------|---------|---------------|---------|
| **问题凭空而来** | "我觉得XX很有意思，所以研究它" | 相关性论证 | 从文献综述中推导出问题 |
| **设计与目的不符** | 想证明因果，却用截面OLS | 设计匹配论证 | 改用准自然实验或明确说只能证明相关性 |
| **数据缺失关键变量** | 想做机制检验，但没有中介变量M的数据 | 资料充分性论证 | 补充数据或调整研究问题 |
| **方法识别不了因果** | 宣称"影响"但只有相关性证据 | 方法有效性论证 | 诚实说明局限或改进识别策略 |
| **理论堆砌** | 引用10个理论但不说明关系 | 理性论证（重要性） | 精选2-3个核心理论，说明如何整合 |
| **黑箱假设** | "X影响Y"但不解释为什么 | 严谨论证（相关性） | 明确中介机制（X→M→Y） |
| **僵化框架** | 数据不支持仍强行解释 | 持续反思 | 诚实修正假设，记录在框架版本中 |
| **框架与实证脱节** | Introduction讲理论，Results只报系数 | 全流程一致性 | 每个表格都要回扣框架中的假设 |

## 🎯 框架质量自检清单

**阶段1：文献综述后（构建理性论证）**
- [ ] 研究问题用一句话清晰陈述了吗？
- [ ] 理论意义（填补什么空白）明确了吗？
- [ ] 现实意义（解决什么问题）有说服力吗？
- [ ] 学术与政策受众定位清楚了吗？

**阶段2：研究设计后（构建严谨论证）**
- [ ] **相关性**：问题是文献综述的自然结论吗？
- [ ] **匹配性**：研究设计与研究目的对应吗？
- [ ] **充分性**：数据包含所有必需变量吗？
- [ ] **有效性**：方法能识别因果（或诚实说明局限）吗？

**阶段3：实证分析后（持续反思）**
- [ ] 所有假设的检验结果都记录了吗？
- [ ] 与预期不符的结果找到原因了吗？
- [ ] 更新了版本号并注明修订理由了吗？
- [ ] 回溯检查了四大严谨论证是否还成立？

**阶段4：论文写作时（全流程一致性）**
- [ ] Introduction 中清晰阐述了理性论证吗？
- [ ] 每个实证结果都回扣了框架中的假设吗？
- [ ] 结论中反思了框架的适用性与局限吗？
- [ ] 审稿人能从框架中看到研究的严谨性吗？

---

**核心思想**：概念框架不是装饰品，而是论文的**论证骨架**。它连接理论与实证，让审稿人看到你不是"数据工"，而是"会思考的研究者"。理性回答"为什么值得做"，严谨证明"我做得对"。
