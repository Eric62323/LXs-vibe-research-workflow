# 产出类型标准 (Output Type Standards)

根据学术成果的不同形式，Vibe Research 工作流的重心与结构会有显著差异。在项目启动（Cycle 0）阶段，必须明确本项目属于以下哪种形式。

## 1. 期刊论文 (Journal Paper)
**核心特征**：注重实证论证与边际贡献。
**重心**：
- **实证检验 (/实证)**：权重最高。必须有严谨的因果识别策略和稳健性检验。
- **理论框架 (/框架)**：相对精简。主要用于引出假设，不需要面面俱到。
- **结构体量**：通常 8,000 - 15,000 字。
- **痛点**：此形式要求"小切口，深挖掘"，拒绝宏大叙事。

## 2. 开题报告 (Research Proposal)
**核心特征**：注重概念框架与可行性。
**重心**：
- **概念框架 (/框架)**：权重最高。要把"为什么做"（选题意义）和"怎么做"（研究设计）讲透。
- **实证检验 (/实证)**：只需展示预期结果或初步探索性数据，无需完整的回归结果。
- **结构体量**：通常 5,000 - 8,000 字。
- **痛点**：核心是说服评审人"这个研究值得做"且"我有能力做"。

## 3. 学位论文 (Dissertation/Thesis)
**核心特征**：注重系统性、完整性与工作量。
**重心**：
- **全要素均衡**：每个板块都需要充实的内容。
- **文献综述 (/审查)**：需要极大幅度的文献回顾，构建完整的知识谱系。
- **实证与机制 (/实证)**：不仅要有主回归，还要有丰富的异质性分析和机制检验。
- **结构体量**：硕士 3-5万字，博士 10万字+。
- **痛点**：核心是展示"系统性的学术训练成果"，要有章节间的逻辑严密性。

---

## 🚀 工作流适配指南

| 产出类型 | Block 1: 框架 | Block 2: 实证 | Block 3: 写作 | Block 4: 审查 |
| :--- | :--- | :--- | :--- | :--- |
| **期刊论文** | 精简，直奔假设 | **核心战场** (严谨性) | 逻辑紧凑，强调贡献 | 针对性引用 |
| **开题报告** | **核心战场** (逻辑/意义) | 预期模型设定 | 清晰展示思路 | 目前掌握的文献 |
| **学位论文** | 完整，宏大背景 | 全面，多维验证 | 篇幅长，结构严谨 | 系统性梳理 |
