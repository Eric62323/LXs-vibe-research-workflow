# 论证推理框架 (Argumentation Reasoning Framework)

> 本文件为概念框架Agent提供推理方法论参考。
> 教Agent"如何思考"论证，而非仅"做什么"。

---

## 一、Toulmin论证模型

将任何论证拆解为6个要素：

1. **主张 (Claim)**：论证的结论，即你想证明的观点
2. **数据 (Data/Grounds)**：支持主张的事实、证据或数据
3. **担保 (Warrant)**：连接数据和主张的推理规则（为什么数据能支持主张？）
4. **支撑 (Backing)**：担保本身的可信度来源（理论、文献、先例）
5. **限定 (Qualifier)**：主张的适用范围和强度（在什么条件下成立？）
6. **反驳 (Rebuttal)**：可能导致主张不成立的例外情况

**使用方法**：

当Agent审查一个论证时，逐项检查：
- 主张是否明确？
- 数据是否充分且可靠？
- 担保是否合理（数据→主张的推理是否成立）？
- 担保是否有支撑（理论/文献支持）？
- 是否正确限定了适用范围？
- 是否考虑了主要的反驳/例外？

**示例（经济学）**：
- **Claim**: 土地流转提高了农民收入
- **Data**: 面板回归显示流转农户收入提高15%
- **Warrant**: 回归中的因果识别策略（DID）可以建立因果联系
- **Backing**: 平行趋势检验通过、安慰剂检验通过
- **Qualifier**: 在非农就业机会充足的地区成立
- **Rebuttal**: 可能是自选择偏误（更积极的农户更可能流转）

## 二、Bradford Hill因果推理准则

9个评估因果关系的标准，适用于实证经济学中的因果推断评估：

1. **强度 (Strength)**：效应量有多大？大效应更可能是因果关系而非混杂
2. **一致性 (Consistency)**：不同研究/样本/方法是否得到相似结果？
3. **特异性 (Specificity)**：原因是否特异性地导致了这一结果？
4. **时间性 (Temporality)**：原因是否确实在结果之前？（唯一必须满足的条件）
5. **生物学梯度 (Biological Gradient / 剂量-反应关系)**：暴露量增加是否导致效应增加？
6. **合理性 (Plausibility)**：因果机制是否与已知理论一致？
7. **连贯性 (Coherence)**：因果解释是否与该领域的其他已知事实一致？
8. **实验证据 (Experiment)**：是否有实验或准实验证据？
9. **类比 (Analogy)**：类似的因果关系是否在其他情境中已被证实？

**在实证经济学中的适配**：

| Bradford Hill准则 | 实证经济学对应 |
|-------------------|---------------|
| 强度 | 系数的经济显著性（不仅仅是统计显著性） |
| 一致性 | 稳健性检验、不同数据集的复制 |
| 特异性 | 机制检验的精确性 |
| 时间性 | 政策冲击的时点、DID的时间结构 |
| 剂量-反应 | 连续型处理变量、分位数效应 |
| 合理性 | 理论机制的经济逻辑 |
| 连贯性 | 与现有文献的一致性 |
| 实验证据 | 自然实验、准实验设计 |
| 类比 | 类似政策在其他国家/地区的证据 |

**使用方法**：

当Agent评估因果推断强度时，逐一检查这9个标准，判断证据的整体说服力。不需要全部满足，但满足越多，因果推断越可信。

## 三、最佳解释推断 (Inference to Best Explanation / Abduction)

**核心思想**：在多个竞争性解释中选择最佳解释。

**评估标准**：
1. **解释力**：该解释能解释多少观察到的现象？
2. **简洁性**：该解释需要多少额外假设？（奥卡姆剃刀）
3. **一致性**：该解释与已知事实是否一致？
4. **可检验性**：该解释能产生可检验的新预测吗？
5. **类比支持**：类似情境下是否有先例？

**使用方法**：

当实证结果可以有多种解释时：
1. 列出所有合理的竞争性解释
2. 用上述5个标准逐一评估每个解释
3. 比较各解释的综合得分
4. 选择得分最高的解释作为"最佳解释"
5. 同时指出最佳解释的薄弱环节

**示例（经济学）**：

实证发现：房地产冲击显著降低劳动力非农就业。
- **解释A（财富效应）**：房价下跌→家庭财富缩水→消费减少→本地就业减少→劳动力留在农业
- **解释B（信贷约束）**：房价下跌→抵押品价值下降→信贷可得性降低→无法获得创业/迁移资金→留在农业
- **解释C（预期效应）**：房价下跌→对未来悲观→风险规避增强→不愿离开稳定的农业

评估：B的解释力最强（能同时解释自雇和迁移行为变化），简洁性中等（需要假设信贷约束存在），但可检验性强（可以检验信贷渠道的中间变量）。

## 四、认知状态分类 (Epistemic State Classification)

将知识主张分为4类，要求Agent在陈述时标注认知状态：

### 4.1 已知 (Known)
经过严格实证验证且被广泛接受的结论。
- **标注方式**：直接陈述
- **例**："在大多数发达国家，教育与收入正相关"

### 4.2 可信 (Probable)
有较强的理论和实证支持，但并非定论。
- **标注方式**："有较强证据表明..." / "根据现有研究..."
- **例**："有较强证据表明土地流转通过信贷渠道影响农户投资"

### 4.3 可能 (Plausible)
理论上合理但实证证据有限。
- **标注方式**："理论上..." / "有理由推测..." / "[plausible]"
- **例**："理论上，数字金融可能通过降低交易成本促进土地流转"

### 4.4 未知 (Unknown)
目前没有足够证据做出判断。
- **标注方式**："尚不清楚..." / "需要进一步研究..." / "[unknown]"
- **例**："尚不清楚在极端气候条件下，上述机制是否仍然成立"

### 使用规则

1. Agent在陈述任何论点时，必须自觉地标注其认知状态
2. **禁止**将"可能"的内容以"已知"的口吻陈述
3. **禁止**将"未知"的内容用看似合理的推理填补（反泄漏协议）
4. 当信息来源为LLM参数记忆而非会话材料时，必须**降级一个认知状态等级**
5. 当发现材料缺失时，标记 `[MATERIAL GAP]`，而非用记忆填补
